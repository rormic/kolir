algorithm is in the public domain; the JavaScript implementation is kolir's

### Matugen template syntax — GPL-2.0-or-later

The remaining templates (`foot-colors.ini`, `terminal-sequences`,
`hyprland-colors.lua`, `quickshell-colors.json`, `gtk3-colors-template.css`,
`gtk4-colors-template.css`, `hyprlock-colors.conf`) are written for kolir and
use the `{{colors.*}}` template syntax that Matugen documents. Matugen itself
is GPL-2.0-or-later, which is compatible with GPL-3.0-only. The GTK and JSON
templates enumerate the complete Material 3 role set, so their token list
necessarily matches other Matugen-based themes; only the ordering and the
consumer code differ.

Upstream: <https://github.com/InioX/matugen>


## Runtime dependencies

These are separate programs that kolir starts over the command line or
Quickshell IPC. They are **not** bundled in this repository and kolir is not
built from their source, so their licenses do not extend to this code. The
list is here so packagers can fill `depends` / `optdepends` and so
contributors know which licenses surround the project.

| Program | License | Role |
| --- | --- | --- |
| Hyprland (`hyprctl`) | BSD-3-Clause | compositor and IPC |
| Quickshell (`qs`) | LGPL-3.0-only | shell runtime (QML host) |
| Matugen | GPL-2.0-or-later | palette generation |
| awww | GPL-3.0-only | wallpaper daemon |
| Foot | MIT | default terminal |
| brightnessctl | MIT | backlight control |
| ddcutil | GPL-2.0-or-later | external monitor brightness |
| grim, slurp | MIT | screenshots |
| wl-clipboard | GPL-3.0-or-later | clipboard |
| libnotify | LGPL-2.1-or-later | notifications |
| wf-recorder | MIT | screen recording (fallback `wl-screenrec`, Apache-2.0) |
| hyprlock, hypridle, hyprsunset, hyprpicker | BSD-3-Clause | lock, idle, night light, colour picker |
| zsh | custom (MIT-style) | shell |
| Python | PSF-2.0 | CLI and helper scripts (stdlib only) |
| Qt 6 (through Quickshell) | LGPL-3.0-only / GPL-3.0-only | UI toolkit |
| ffmpeg | GPL-3.0-only | lock background, thumbnails, encoder probes |
| cliphist | GPL-3.0-only | clipboard history |

| UPower | GPL-2.0-or-later | battery indicator |
